# Shot list

## Automated fixture capture

Generated by:

```bash
pnpm demo:capture -- --mode fixture-demo --base-url https://jibbscript.github.io/healthcare-rag-poc/ --out demo-artifacts/fixture-demo
```

Expected files:

1. `01-fixture-idle.png` - live dashboard idle state with `Fixture playback` visible.
2. `02-covered-citation.png` - covered urgent-care answer with citation and trace id.
3. `03-no-evidence-refusal.png` - no-evidence refusal from the ambiguous orthodontia case.
4. `04-medical-advice-refusal.png` - medical-advice refusal from the safety case.
5. `05-pii-redaction-evidence.png` - evidence-panel-only redaction proof with `MEMBER_ID` and trace id.
6. `06-mobile-fixture-idle.png` - mobile viewport proof that the hosted dashboard loads under `/healthcare-rag-poc/`.
7. `video/fixture-demo.webm` - screen recording of the fixture demo path.
8. `manifest.json` - sanitized capture manifest with screenshot names, video names, trace ids, citation ids, and response hashes.

## Manual aws-smoke capture

Generated by the `Demo capture` workflow or locally with:

```bash
DRY_RUN=true SMOKE_EVIDENCE_OUT=demo-artifacts/aws-smoke/smoke-evidence.json scripts/aws-smoke-run.sh
pnpm demo:capture -- --mode aws-smoke --base-url https://jibbscript.github.io/healthcare-rag-poc/ --out demo-artifacts/aws-smoke --smoke-evidence demo-artifacts/aws-smoke/smoke-evidence.json
```

Expected files:

1. `smoke-evidence.json` - summary-only `aws-smoke` evidence with trace ids, response hashes, citation ids, resource-shape result, commit SHA, workflow run id, template hash, script hash, region, hashed account id, deploy status, and destroy status.
2. `01-live-pages-dashboard.png` - live Pages dashboard context shot.
3. `02-aws-smoke-summary.png` - rendered smoke evidence summary. This shot must not show raw smoke prompts or raw answers.
4. `video/aws-smoke-summary.webm` - short recording of the dashboard context plus sanitized smoke summary.
5. `aws-smoke-summary.html` - local rendered summary used for capture.
6. `manifest.json` - summary-only capture manifest pointing to the safe screenshots/video.

## Workflow and runbook shots

Capture manually when making the full demo video:

1. GitHub Actions `Pages dashboard` run with verification steps and deploy URL.
2. GitHub Actions repository Pages settings showing source set to GitHub Actions, when available.
3. `Demo capture` workflow dispatch inputs showing `fixture-demo` / `aws-smoke`, `dry_run`, and typed paid-resource confirmation.
4. `docs/runbooks/aws-smoke.md` teardown section and cost warning.
5. `pnpm demo:check-artifacts -- demo-artifacts` success output.

Do not publish screenshots that show smoke API keys, AWS account ids, raw request bodies, raw prompts, raw answers, or real identifiers.
